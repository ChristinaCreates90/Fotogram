📸 Fotogram

Fotogram is a responsive photo gallery built with HTML, CSS and JavaScript.

Users can browse through a collection of images, open photos in a larger view and navigate through the gallery.

✨ Features
Responsive image gallery
Interactive image dialog
Previous and next image navigation
Keyboard navigation
Image counter
Image descriptions
Close dialog with the ESC key
Close dialog by clicking outside
🛠️ Technologies
HTML5
CSS3
JavaScript
